# 塵骸魔京 体验版 简体中文汉化补丁

《塵骸魔京》（Jingai Makyou）体验版的简体中文汉化补丁，仅替换一个文件 `data.xp3`。

---

## ⚠ 请注意：这是体验版，不是完整版

本补丁对应 VNDB **[v44271](https://vndb.org/v44271)**，即 2003 年 Comic Market
发布的废弃体验版（scrapped version），与 2005 年的最终版
**[v400](https://vndb.org/v400)** 是两个不同的东西——剧情、立绘、演出均有差异。

体验版流程很短（VNDB 标注约 18 分钟），并在中途直接中断：

> 「体験版『塵骸魔京』は、ここで終わります。」
> （体验版《塵骸魔京》到此结束。）

**最终版（v400）不在本补丁的汉化范围内。**

## 使用教程

不需要替换任何 exe，也不需要安装任何运行库。

1. 从 [Releases](../../releases) 下载 `data.xp3`。
2. 找到你的体验版游戏目录（里面应有 `jingai.eXe`、`data.xp3` 等文件）。
3. **先备份原来的 `data.xp3`**（改名成 `data.xp3.bak` 之类即可）。
4. 把下载的 `data.xp3` 放进游戏目录覆盖原文件，然后运行 `jingai.eXe`。

卸载：删掉汉化版 `data.xp3`，把备份改回原名。

> 存档位于游戏目录下的 `savedata\`，与 `data.xp3` 无关，替换补丁不会清空存档。

## 汉化范围

- **剧情文本**：`scenario/first.ks` 全部可见文本，包括旁白、对白、选项、标题演出、
  死亡场景的逐拍追加文字、制作人员名单。

- **其他剧本**：`scenario/about.ks`、`scenario/sample-movescroll.ks`。
- **字体**：`ＭＳ Ｐ明朝` → `宋体`；童话段落原有日文字体 `ＨＧ創英角ﾎﾟｯﾌﾟ体` → `楷体`。

## 顺带修复的技术问题

这是本补丁除了翻译之外最值得说明的部分。

### 1. 原版在中文 Windows 上根本无法启动

原版归档中的 `system/HistoryLayer.tjs` 含有 **6 个不是合法 GBK 的字节**
（来自 Shift_JIS 的符号区）。中文 Windows 下引擎按 GBK 解码时，这些字节会
**把紧随其后的引号一起吞掉**，导致字符串未闭合：

```
文法エラーです at line 95
文字列定数/正規表現/オクテット即値が終わらないままスクリプトの終端に達しました at line 1005
文法エラーです at historylayer.tjs line 95
trace : initialize.tjs(91)[(function) KAGLoadScript]
```

`HistoryLayer.tjs` 整份加载失败 → `initialize.tjs` 中断 → **游戏进程活着，
但永远不出现窗口**（CPU 空闲、只加载 5 个模块，看起来像"卡死"）。

本补丁已将该文件改为纯合法 GBK 字节，可直接启动。

### 2. 换行禁则表整张失效

`HistoryLayer.tjs` 与 `MessageLayer.tjs` 各有一份行首／行末禁则表，
原本是 Shift_JIS 字节，在 GBK 环境下整张变成乱码，对中文排版**完全无效**
（行首可能出现标点、开括号被甩到行末）。已按简体中文规则重写。

### 3. 日文文件名引用失效

剧本中有 `rule="円形(中から外へ)"` 这类引用日文文件名的地方。日文假名在 GBK 中
不存在，无法用编码技巧保留，因此把被引用的 3 个转场图片在归档内改为 ASCII 名
（`circle_center_out` / `wave` / `diag_ur_ll`）并同步修改剧本引用。

## 已知问题

如实列出，均不影响主要流程的可玩性：

1. **制作人员名单部分词条略微偏左。**
   名单是逐字渲染的（每个字一层，落到固定坐标）。日文「スプリクト」5 个字占
   5 个位置，中文「脚本」只有 2 个字，因此会偏左约 36px（约屏宽 6%）。
   强行凑字数会让译名生硬，故保持现状。
2. **开发者信息仍为日文。**
   `dm()` 调试输出、`throw new Exception(...)` 文案、内部层名与代码注释未翻译。
   这些玩家看不到，且原版在中文 Windows 下同样显示为乱码。
3. **历史记录（履历）窗口的实际换行效果未实测。**
   禁则表已按简体规则重写，但自动化无法打开该窗口截图确认，需要人工看一眼。
4. **分支选项的实际走向未逐一点击验证。**
   选项文本已全部汉化并在文件级校验通过，但两处分支的不同结果未人工走完。
